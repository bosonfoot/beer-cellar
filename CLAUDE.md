# Beer Cellar — Project Instructions

## Git commits
- **Auto-commit is OK** for dark/hidden changes (features gated behind auth or READ_ONLY, backend-only changes, localhost-only UI).
- **Ask before committing** anything that changes the appearance or behavior of the public GitHub Pages site for unauthenticated visitors. These should be bundled into deliberate version releases.
- Do not commit or push as a side effect of fixing bugs, restoring files, or running export scripts unless the change is dark.
